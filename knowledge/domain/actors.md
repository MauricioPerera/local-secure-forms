# Actores y responsabilidades

| Actor | Puede hacer | No puede hacer |
|---|---|---|
| Usuario | Completar, revisar, aceptar, rechazar y cancelar | Delegar su confirmación al agente sin verla |
| Agente | Solicitar una operación y leer su estado | Leer secretos, PIN o códigos; confirmar por sí mismo |
| Cliente LSFA | Validar, presentar, confirmar y ejecutar | Ocultar el alcance o rebajar el riesgo declarado |
| Almacén seguro | Guardar y recuperar secretos para la operación autorizada | Exponer el secreto al agente |
| Sistema externo | Recibir el efecto autorizado | Ejecutar una acción no confirmada |
